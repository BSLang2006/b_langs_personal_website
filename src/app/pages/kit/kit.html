Everything a write-up can use. None of it needs importing and none of it needs a stylesheet — write the class, get the block. Each one below is shown as it renders, with the markup that made it underneath.

Start here

The whole file for a new post. Copy it into my-new-post.html and write over the placeholders.

There is no date and no title in it: <app-entry> draws the header from posts.ts, so the only thing in this file is what you have to say. 

<app-entry>
  <p class="lead">
    What today was about, in a sentence or two.
  </p>

  <h2>The thing that stumped me</h2>

  <p>
    What happened, and what the command was that cracked it.
  </p>

  <p class="summary">The one-line takeaway.</p>

  <h2>Also today</h2>

  <ul>
    <li>The other things that fought you.</li>
  </ul>

  <p class="summary">What you are doing next.</p>
</app-entry>

Open with a .lead, close each section with a .summary. Those two do most of the work — everything below is for when a post needs more.

Notes

An aside from the main line of the post. Three flavours.

Plain. Something worth saying that is not part of the argument.

The trap. The router uplink's acceptable frame type was untagged-only, and tagged frames were discarded before they reached anything else.

The thing that showed it was fixed. The NIC pulled a 10.10.99.xxx address.

Any note can carry its own label instead of the default.

Breaking the column

The reading column is 640px, which is right for prose and wrong for a diagram. .wide steps outside it and stays centred — put it on a div, a figure, or a table wrapper. 

<div class="wide"><app-my-diagram /></div>

<figure class="wide">
  <img src="…" alt="…" />
  <figcaption>What to look at.</figcaption>
</figure>
