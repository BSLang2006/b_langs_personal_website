Today I felt that I was able to finally learn in the way that suits me.

The thing that stumped me

VTP has to be in transparent mode to allow a config file add a VLAN to the database

I almost decided to give up and just manually enter the vlan information for every device after they turned on for the first time. But that was not going to pass muster, automation was the reason I built this. Automation was the reason I spent an entire weekend building a management plane. I persisted.

I stripped the config file down to nothing to only add the vlan to the hostname, database, and a console line. Still no joy, the vlan would not take, every other thing I put in the config file was taking... |show vtp status| was the command that cracked the nut. |VTP mode server| was set, and I didn't think it was the fix because you need to set VLANS on the server right? I flipped it to transparent and my config file was able to upload VLAN information to the database with |VTP mode transparent| set.
